# Vusi Erasa verify page

Static page that checks the Ed25519 signature on a Vusi Erasa data-erasure certificate, entirely in the browser. Nothing is uploaded.

Served at https://damox101za.github.io/erasa-verify/

This repository is a published copy of `web/verify` from Vusi Erasa. Make changes there, not here.
